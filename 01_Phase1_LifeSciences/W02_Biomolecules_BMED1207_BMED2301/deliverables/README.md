# Week 2 Deliverables — Biomolecules & Biochemistry

## Deliverable 1: Enzyme Kinetics Problem Set

- **Type**: Problem Set
- **Deadline**: End of Week 2

### Requirements

1. **Michaelis-Menten Calculations** (20 points)
   - Given v vs [S] data, determine Vmax and Km graphically and analytically
   - Convert units between μmol/min and nM/s

2. **Inhibition Analysis** (30 points)
   - Distinguish competitive, non-competitive, and uncompetitive inhibition
   - Analyze Lineweaver-Burk plots
   - Calculate Ki from experimental data

3. **Protein Structure Prediction** (20 points)
   - Given amino acid sequence, predict secondary structure
   - Calculate isoelectric point
   - Analyze hydrophobicity profile

4. **Nucleic Acid Calculations** (15 points)
   - Calculate molecular weight of DNA fragments
   - Predict melting temperature (Tm)
   - Analyze restriction enzyme digestion patterns

5. **Clinical Correlation** (15 points)
   - Interpret serum enzyme levels
   - Connect molecular mechanism to clinical presentation

- **Deadline**: End of Week 3
