# 📋 00_Planning — 規劃文件

本資料夾包含 HKU BME 24 週訓練營的兩份核心規劃文件（中英對照）。

## 文件清單

| File | 用途 |
|------|------|
| `HKU_BME_24Week_Bootcamp_Plan_Bilingual.xlsx` | 24 週詳細計劃（每週 objectives、pre-reading、coding labs、deliverables、自測重點） |
| `HKU_BME_37_Course_Mapping_Matrix.xlsx` | 37 個 HKU BEng(BME) 課程完整對應矩陣 |

## 使用方法

1. 開啟 Excel 檔案，filter by Phase 一次睇一個 stage
2. 每週末開始前，copy 對應 weekend row 到你嘅 Obsidian/Notion notes
3. 完成 deliverables 後，update `../Master_Tracking.md`
