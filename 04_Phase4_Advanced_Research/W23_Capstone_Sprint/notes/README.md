## Literature Review Structure

### 1. Introduction
- Context and importance of the problem
- Scope of the review
- Organization of the section

### 2. Body (Thematic or Chronological)

**Thematic Organization** (recommended for most projects):
```
Topic 1: Background on Problem
  - Subtopic A
  - Subtopic B

Topic 2: Current Approaches
  - Approach 1
  - Approach 2

Topic 3: Limitations of Current Approaches
  - Limitation 1
  - Limitation 2

Topic 4: Proposed Solution Framework
  - Our approach
```

### 3. Gap Identification
- What is NOT known?
- What approaches have failed?
- Why is this important to solve?

### 4. Research Questions / Hypotheses
- Specific, testable questions
- Clear hypotheses with predictions

## Methodology Design

### Engineering Methods Framework

| Project Type | Methods |
|-------------|---------|
| Tissue Engineering | Cell culture, scaffold fabrication, characterization, animal model |
| Biomaterials | Material synthesis, mechanical testing, degradation studies, in vitro assays |
| Signal Processing | Algorithm development, validation datasets, performance metrics |
| Computational | Model development, simulation, experimental validation |
| Device Design | CAD, prototyping, bench testing, usability testing |

### Controls and Validation

**Essential Controls**:
1. **Negative control**: Without treatment/sample
2. **Positive control**: Known standard
3. **Baseline**: Pre-treatment measurement
4. **Reference**: Industry standard comparison

**Validation Strategy**:
- Technical validation (does method work?)
- Biological validation (is it meaningful?)
- Clinical validation (does it translate?)

## Preliminary Results Structure

### Quantitative Results
1. **Descriptive statistics**: Mean, SD, N
2. **Visualization**: Plots with error bars
3. **Statistical tests**: Appropriate comparisons
4. **Effect sizes**: Practical significance

### Qualitative Results
1. **Themes identified**
2. **Representative examples**
3. **Frequency/counts**
4. **Integrative analysis

### Expected Findings Template

```
Results Summary:
- N = [number] samples/measurements
- Primary outcome: [what was measured]
- Key finding: [main result with statistics]
- Secondary findings: [additional observations]

Figures:
- Figure 1: [description]
- Figure 2: [description]
```

## Discussion Writing Guide

### Structure

1. **Summary of Key Findings** (1 paragraph)
   - Restate main results without data
   - Address each hypothesis

2. **Interpretation** (2-3 paragraphs)
   - How do findings compare to literature?
   - What mechanisms might explain results?
   - What is the practical significance?

3. **Limitations** (1 paragraph)
   - Sample size, method constraints
   - Generalizability limitations
   - Confounding factors

4. **Future Directions** (1 paragraph)
   - Next experimental steps
   - Scaling up
   - Clinical translation pathway

5. **Conclusion** (1 paragraph)
   - Take-home message
   - Broader impact

### Correctness
- [ ] Statistics appropriate

- [ ] References accurate
- [ ] No plagiarism

---

## Common Mistakes to Avoid

1. **Literature review**: Just summarizing, not synthesizing
2. **Methodology**: Vague descriptions, missing details
3. **Results**: No statistics, no error bars, no controls
4. **Discussion**: Repeating results, ignoring limitations
5. **References**: Inconsistent formatting, wrong style
