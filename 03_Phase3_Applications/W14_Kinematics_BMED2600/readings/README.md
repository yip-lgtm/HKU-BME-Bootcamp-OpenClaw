## Learning Objectives (BMED2600)
By the end of Week 14, students should be able to:
1. Describe the gait cycle phases (stance 60%, swing 40%) and sub-phases
2. Compute joint angles from marker trajectories using 3D rotation mathematics
3. Apply inverse dynamics (Newton-Euler) to calculate joint torques
4. Analyze ground reaction forces (GRF) during walking and running
5. Explain fracture patterns in long bones under various loading modes
