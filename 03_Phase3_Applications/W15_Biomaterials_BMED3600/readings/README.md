  - Chapters 6-8: Degradation, wear, testing methods
- **Park, J. & Lakes, R.S.** (2007) *Biomaterials: An Introduction*, 3rd ed. — Springer. ISBN: 978-0387379800
  - Chapters 3-5: Material classes (metals, ceramics, polymers)
  - Chapters 7-9: Biological responses, testing, applications

## Learning Objectives (BMED3600)
By the end of Week 15, students should be able to:
1. Classify biomaterials by material class (metal, ceramic, polymer) and by application
2. Explain surface energy, roughness, and contact angle effects on biocompatibility
3. Describe host response to biomaterials (inflammation, fibrous encapsulation, thrombosis)
4. Analyze degradation mechanisms: corrosion, hydrolysis, enzymatic degradation
5. Compare material properties relevant to orthopaedic, cardiovascular, and tissue engineering applications
